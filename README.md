# SquareHub Android

X → Chia sẻ → SquareHub → Xem trước → Đăng lên Binance Square.

Dùng đúng "Square OpenAPI" chính thức của Binance
(binance.com/vi/skills/detail/binance/square-post).

## Cách lấy file cài đặt (APK) mà không cần cài Android Studio

1. Đẩy (push) toàn bộ thư mục này lên một repository GitHub (có sẵn
   file `.github/workflows/android-build.yml`).
2. Vào tab **Actions** trên GitHub, workflow "Android Build" sẽ tự
   chạy và build ra file APK.
3. Bấm vào lần chạy mới nhất → phần **Artifacts** → tải file
   `SquareHub-android-debug-apk` về (là file .zip chứa app-debug.apk).
4. Chuyển file `app-debug.apk` sang điện thoại Android (qua email, Zalo
   gửi cho chính mình, Google Drive, USB...).
5. Trên điện thoại, mở file .apk đó lên để cài. Nếu bị chặn, vào
   Cài đặt → cho phép "Cài đặt ứng dụng không rõ nguồn gốc" cho trình
   duyệt/app bạn dùng để mở file, rồi thử cài lại.

## Cách dùng

1. Mở app SquareHub → nhập API Key (lấy tại
   binance.com/square/creator-center/home) → bấm Lưu.
2. Mở app X → chọn bài viết → bấm Chia sẻ → chọn SquareHub.
3. Xem trước nội dung → bấm "ĐĂNG LÊN SQUARE".
